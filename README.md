# FACE-TO-FACE

Vite + React application prepared for Vercel deployment.

## Deploy
1. Replace the repository contents with these files.
2. Commit and push to the `main` branch.
3. Redeploy on Vercel.

The source file `src/main.jsx` is complete JSX with balanced component and HTML/JSX structure.

## Optional live translation
Set `VITE_TRANSLATE_URL` in Vercel Environment Variables to a compatible translation API endpoint.
